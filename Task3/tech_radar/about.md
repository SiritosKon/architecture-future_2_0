# Как пользоваться радаром

Радар показывает технологии работы с данными в «Будущем 2.0»: какие используем сейчас, какие внедряем в целевой архитектуре и от каких отказываемся.

### Релизы

- **2026-09-01** — текущее состояние: DWH на SQL Server 2008, ESB на Apache Camel, PowerBuilder, Power BI, сервисы на Go, Java и Python.
- **2026-10-11** — целевая архитектура через год: Data Mesh на облачной платформе. Технологии с меткой «Новое» появились в этом релизе, с меткой «Изменено» — сменили кольцо.

### Кольца

- **Используем** — технология входит в целевую архитектуру.
- **Пробуем** — внедряем на первых доменах и проверяем.
- **Изучаем** — решение примем по итогам пилота.
- **Выводим** — не развиваем, постепенно отказываемся.

### Теги

Теги показывают, какой бизнес-сценарий поддерживает технология: `отчётность`, `независимость`, `масштаб`, `безопасность`. Тег `легаси` отмечает технологии текущего ландшафта, от которых отказываемся.
